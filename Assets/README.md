# Artwork

Custom artwork created with the imagegen skill for GabbaProcTracker.
`Icon-source.png`: square fantasy medallion with a turquoise lightning strike
and three gold statistics bars. `Minimap-source.png`: separate circular variant
with transparent corners and a gold rim. No externally copied game artwork.

Runtime textures: `Icon.tga` (128×128 RGBA), `Minimap.tga` (64×64 RGBA),
8-bit channels, uncompressed TGA. CurseForge uses `curseforge/logo.png` (400×400).
The circular asset already contains its rim, so the button adds no rectangular
background or second border. Source PNGs are kept for future edits; only TGA
textures are included in installable release ZIPs.
